대학알리미 데이터 활용

대학알리미 기반 진로·학과 트렌드 분석 보고서

전국 주요 대학 학과별 경쟁률, 취업률 및 신입생 충원율 데이터 종합 해석

대학알리미의 공시 데이터를 바탕으로 계열별 취업률 변화와 학과 선호도 추이를 탐색했습니다. 데이터에 기반한 진로 탐색 경로와 유망 분야 트렌드 가이드를 제시합니다.

사용 데이터: 대학알리미 학과별 공시 정보 (취업률, 입시 경쟁률 등)
분석 도구: Python (Pandas, Matplotlib), Seaborn
주요 성과: 계열별 취업률 변화 분석 및 맞춤형 진로 방향 도출

도로교통공단 데이터 활용

도로교통공단 공공데이터 기반 교통사고 위험지역 분석

지역별 보행자 사고 다발지역 원인 파악 및 공간 데이터 지도 시각화

도로교통공단 TAAS 시스템 데이터를 연계하여 시간대별·유형별 교통사고 발생 건수를 분석했습니다. GIS 지도 시각화를 활용하여 보행자 위험 구역을 식별하고 개선안을 제안합니다.

사용 데이터: 도로교통공단 교통사고 다발지역 및 GIS 데이터
분석 도구: Python (Folium, GeoPandas), QGIS
주요 성과: 어린이 보호구역 및 야간 보행 위험지역 맵핑
